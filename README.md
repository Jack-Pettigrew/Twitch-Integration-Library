# Twitch-Integration-Library
A Twitch Integration Library for C# based Video Games and Apps.

Connect your app to Twitch and create engaging experiences. Embed chat features or make your application react to Twitch events.

- Built, tested and utilised within Godot first and foremost.
- Striving to be engine-agnostic.
- Ease and simplicity first.
- Event-driven integration.
- Based on the Device Code Grant Flow with automatic token refresh.
